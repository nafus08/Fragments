# Fragments

An Android learning project demonstrating fragments and several Android platform features through a navigation-drawer-based sample app.

## Tech stack

- Kotlin
- Android SDK and AndroidX AppCompat
- AndroidX Navigation
- Material Components and View Binding
- Glide for image loading
- Gradle with Kotlin DSL

## Demonstrations

- Fragment navigation for broadcast, image-scaling, video, and audio examples
- Broadcast receiver example with a custom broadcast input/receiver flow
- Battery notification activity
- Image scaling and media playback examples
- Navigation drawer and toolbar integration

## Run locally

1. Clone the repository:

   ```bash
   git clone https://github.com/nafus08/Fragments.git
   ```
2. Open the project root in Android Studio and sync Gradle.
3. Run the `app` configuration on an Android emulator or connected device.

The project supports Android 5.0 (API 21) and later.
